# LinkToMeshulam

Landing page for the "ורוממתנו!" campaign — Carmei Lubavitch synagogue expansion fundraiser (Carmei Gat). Static site (HTML/CSS/vanilla JS, no build step) that tells the campaign story and funnels visitors to the synagogue's Meshulam donation page.

- [docs/SPEC.md](./docs/SPEC.md) — product spec
- [docs/plan.md](./docs/plan.md) — build plan derived from the spec
- [docs/tasks.md](./docs/tasks.md) — 10-task breakdown, each ending in a GitHub push, deployed to Vercel at the end

## Local dev

No build step — open `index.html` directly in a browser, or serve the folder with any static file server.
